# 海澄村三色资源游戏UI预览图生成提示词

## 整体风格要求
- 设计风格：卡通化、简洁明了、色彩鲜艳
- 目标受众：全年龄段用户，重点面向青少年和年轻成人
- 设计理念：融合海澄村的文化元素，突出三色资源的特色
- 色彩方案：
  - 非遗：#FF5722（橙色）
  - 自然：#4CAF50（绿色）
  - 红色：#F44336（红色）
  - 背景色：#F5F5F5（浅灰色）
  - 文字色：#333333（深灰色）
