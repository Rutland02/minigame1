# 成就清除按钮添加说明

## 功能说明

本文档描述如何在成就页面添加"清除成就"按钮，用于快速清除所有已解锁的成就。

## 添加步骤

### 1. 恢复按钮绘制代码

在 `code/js/pages/成就页/index.js` 文件的 `renderBottomButtons` 方法中添加以下代码：

```javascript
// 绘制清除成就按钮 - 底部右侧（调试用）
const clearButtonX = this.width - 40 - buttonWidth;
this.drawRoundedRect(ctx, clearButtonX, buttonY, buttonWidth, buttonHeight, 25);
const clearGradient = ctx.createLinearGradient(clearButtonX, buttonY, clearButtonX + buttonWidth, buttonY + buttonHeight);
clearGradient.addColorStop(0, '#EF4444');
clearGradient.addColorStop(1, '#DC2626');
ctx.fillStyle = clearGradient;
ctx.fill();
ctx.strokeStyle = 'rgba(0, 0, 0, 0.3)';
ctx.lineWidth = 2;
ctx.stroke();
ctx.fillStyle = '#ffffff';
ctx.font = '14px Arial';
ctx.textAlign = 'center';
ctx.fillText('清除成就', clearButtonX + buttonWidth / 2, buttonY + 32);
```

### 2. 恢复点击处理逻辑

在 `handleTouchStart` 方法中添加以下代码：

```javascript
// 检查是否点击了清除成就按钮 - 底部右侧
if (x >= this.width - 140 && x <= this.width - 40 && y >= this.height - 80 && y <= this.height - 30) {
  this.clearAllAchievements();
  return;
}
```

### 3. 恢复清除成就方法

在 `AchievementPage` 类中添加以下方法：

```javascript
// 清除所有成就
clearAllAchievements() {
  const databus = this.getDatabus();
  const clearedCount = databus.clearAllAchievements();
  
  wx.showToast({
    title: `已清除 ${clearedCount} 个成就`,
    icon: 'success',
    duration: 2000
  });
  
  console.log('[成就页面] 已清除成就:', clearedCount);
}
```

## 功能说明

- **按钮位置**：成就页面底部右侧，红色按钮
- **功能**：点击后清除所有已解锁的成就
- **提示**：点击后会显示 Toast 提示清除的成就数量
- **调试**：控制台会显示详细的调试信息

## 注意事项

- 此功能仅用于开发和测试目的
- 清除成就后，所有已解锁的成就将被重置
- 清除操作不可逆，请谨慎使用
